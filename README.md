## Käyttöohje

Ohjelman käyttö vaatii pythonista vähintään version 3.10 ja poetrystä vähintään version 2.0.

1. Kopioi ohjelma etärepositoriosta itsellesi.

2. Asenna riippuvuudet:

'''bash
poetry install
'''
